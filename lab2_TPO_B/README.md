# Лабораторна робота: Створення та використання потоків (Варіант №8)

## Опис проєкту

Windows Forms застосунок (.NET 8) для обчислення кусково-заданої функції з використанням потоків та таймера.

## Завдання

Розробити програму, що обчислює значення функції:
```
f(x) = 2 / (x^2 + 1),           якщо -3 <= x <= 3
f(x) = |x^3 - 7| / x,           у інших випадках
```

## Технічні вимоги

? .NET 8, net8.0-windows
? Windows Forms (UseWindowsForms=true)
? System.Windows.Forms.Timer для інкрементування аргументу
? System.Threading.Thread для виконання обчислень в окремому потоці
? Обробка винятків при недопустимих значеннях (x=0 у другій гілці)
? Безпечне оновлення UI з фонового потоку через Invoke()

## Структура файлів

### FunctionCalculator.cs
- Клас `FunctionCalculator` з методом `Calculate(double x): double`
- Реалізує кусково-задану функцію з явною перевіркою на x=0
- Генерує власний виняток `FunctionArgumentException` при недопустимому значенні

### Program.cs
- Стандартна точка входу для WinForms застосунку
- STAThread для коректної роботи Windows Forms

### Form1.cs
- Логіка керування застосунком
- Обробник подій таймера (Timer_Tick)
- Створення та запуск потоків для обчислення функції
- Безпечне оновлення DataGridView з іншого потоку через Invoke()

### Form1.Designer.cs
- Дизайнер форми з усіма UI компонентами

## Компоненти форми

- **nudArgument** (NumericUpDown) — поточне значення аргументу X, інкрементується таймером
- **txtStep** — крок інкременту за один тік таймера (за замовчуванням 0.5)
- **txtInterval** — інтервал таймера в мілісекундах (за замовчуванням 500)
- **txtMinX** — мінімальне значення X (за замовчуванням -10)
- **txtMaxX** — максимальне значення X (за замовчуванням 10)
- **btnStart** — кнопка "Почати обчислення"
- **btnStop** — кнопка "Зупинити"
- **btnClear** — кнопка "Очистити таблицю"
- **dgvResults** — таблиця результатів з колонками: X, F(x), ID Потоку
- **lblStatus** — рядок статусу для повідомлень

## Особливості реалізації

### Вибір NumericUpDown для аргументу
NumericUpDown вибраний тому, що:
1. Дозволяє явно контролювати числове значення аргументу
2. Надає зручний UI для перегляду та редагування значення
3. Легко конвертується з decimal в double
4. Дозволяє користувачеві вручну змінювати значення

### Безпека потоків
Обчислення функції виконується в окремому потоці System.Threading.Thread.
Оновлення UI здійснюється через `this.Invoke()`, що маршалює виклик до потоку UI.
Це запобігає помилкам "Cross-thread operation not valid" в WinForms.

### Послідовність обчислень
Перед створенням нового потоку дочекаємося завершення попереднього через `calcThread.Join()`.
Цей підхід простіший і безпечніший для даної задачі, оскільки не потрібна справжня паралельність.

### Обробка помилок
- Перевірка формату вводу при зчитуванні параметрів
- Перевірка адекватності параметрів (minX < maxX, step > 0, interval > 0)
- Обробка FunctionArgumentException при x=0 у другій гілці функції
- Обробка будь-яких інших винятків без припинення роботи застосунку
- Всі повідомлення про помилки виводяться українською мовою в lblStatus

## Як запустити

1. Відкрити проєкт в Visual Studio
2. Побудувати рішення (Build > Build Solution)
3. Запустити застосунок (F5 або Debug > Start Debugging)
4. Натиснути "Почати обчислення" для запуску
5. Спостерігати результати в таблиці
